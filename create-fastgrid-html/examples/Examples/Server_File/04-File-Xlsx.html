4. XLSX sheets from file server

Loading sheets XLSX data from and saving data to file on Node server
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/File.js?func=getbin&file=Excel.xlsx and saved to url http://localhost:8000/File.js?func=setbin&file=Excel.xlsx. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in XLSX file ./server/Excel.xlsx and the script loading and saving data is located at ./server/File.js
