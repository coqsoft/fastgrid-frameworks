7. Excel 1M rows example

Spread sheet example opening maximal 1,000,000 rows xlsx file by default. The large xlsx file is loaded from treegrid.com.
Spread sheet configuration is in Angular component source at ./src/app/examples/sheet/07-excel-1M.component.ts, XLSX file is downloaded from https://www.treegrid.com/FExamples/Complex/07-Excel1M/Excel1M.xlsx

Drop or paste any .xlsx or .csv file to the grid to open and edit it here! Or open any .xlsx or .csv file from your disk by click to icon on toolbar.
The xlsx files can be opened, edited and saved (by or icon) directly in browser, without any communication with server!
