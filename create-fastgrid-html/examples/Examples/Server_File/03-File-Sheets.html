3. JSON sheets from file server

Loading sheets JSON data from and saving data to file on Node server
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/File.js?func=get&file=SheetsData.js and saved to url http://localhost:8000/File.js?func=set&file=SheetsData.js. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in JSON file ./server/SheetsData.js and the script loading and saving data is located at ./server/File.js
