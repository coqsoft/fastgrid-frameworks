1. Plain table from SQL server

Loading data from and saving data to SQLite database table on Node server
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/SQLTable.js?func=get and saved to url http://localhost:8000/SQLTable.js?func=set. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in ./server/sqlite.db database file in table TableData and the script loading and saving data is located at ./server/SQLTable.js
