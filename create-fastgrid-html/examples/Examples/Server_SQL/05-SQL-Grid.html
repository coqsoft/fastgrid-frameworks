5. Grid from SQL server

Generates grouped grid from plain table by dynamic layout script. Using SQLite database table on Node server.
  • Generates treetable from standard database table. Also flips the table and shows data in changed layout. For every action there is used another support code (Layout, Data, Upload). The layout is also generated.
    Rows are identified by one unique editable column, with using full ids (including parents ids). For demonstration it shows id column, to see what ids are generated by FastGrid.
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample layout is loaded from http://localhost:8000/SQLGrid.js?func=getdef, the sample data are loaded from http://localhost:8000/SQLGrid.js?func=getdata and changes are saved to url http://localhost:8000/SQLGrid.js?func=set. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in ./server/sqlite.db database file in table TableData and the script loading and saving data is located at ./server/SQLGrid.js
