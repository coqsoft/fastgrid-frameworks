8. CSV grid

Basic grid loaded from CSV data

  • Loading CSV


    • CSV data or its url can be directly passed to FastGrid like JSON, like <fast-grid src="08-Csv_grid.csv"/>
    • If the CSV file url has not extension csv, set also Format="csv" like <fast-grid src={Format:'csv',Url:'08-Csv_grid.csv'}/>
    • If passing CSV directly in string, set also Format="csv" like <fast-grid src={Format:'csv',Data:'...'}/>

  • CSV separators

    • By default the input CSV has separated columns by comma, the rows by CR or LF or CRLF and quoted valued by double quote.
    • To specify different separators, set Cfg attributes CsvRowSeparator, CsvValueSeparator and CsvQuote
    • For example <fast-grid src=[{Cfg:{CsvValueSeparator:';'}},{Format:'csv',Data:'a;b;c\nd;e;f'}]/>

  • CSV layout

    • The data rows are always created from CSV and added to default row part or to part specified by Cfg CsvRows.
    • By default the columns are created from CSV in default column part. It is possible to define the columns in JSON layout and set Cfg CsvCols to empty string to not create them from CSV.
    • It is possible to define Header rows in JSON layout or create them from first lines in CSV by Cfg attribute CsvHeaderRows.
    • It is possible to define Header columns in JSON layout or create them from first columns in CSV by Cfg attribute CsvHeaderCols.
