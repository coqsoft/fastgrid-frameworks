4. Searching in cells

Focus or highlight cells or select or show rows that satisfy selected criteria
Source: 04-Search.js

  • Changing search


    Search control can be added to grid by toolbar D: Search.
    This toolbar contains two cells by default, search combo as tool D: SearchText that permits entering text to search. The search starts by pressing enter. The combo can show also popup list of search history and search off item.
    The next cell on the Search toolbar is search button as tool D: Search that performs next search (usually for focus search) and can show search options in popup list.
    The search can be run also by API method Search.

  • Setting search


    Text to search is set in Cfg attribute SearchText. It can contain more words separated by space that can be searched together or separatelly according to setting SearchMulti.
    Performed search action is set in Cfg attribute SearchAction. The available search actions are focus, color (cells or rows), select or filter.
    The search can store the found rows or cells in Cfg attributes FoundRows / FoundCells / FoundBlocks if SearchAction contains appropriate action.
    To perform any search, the SearchAction must contain keyword Search.

  • Search operators


    There are 18 search operators that can be assigned to Cfg SearchCompare attribute as numbers 1 - 18:
    Number search:1 - Equal, 2 - Not equal, 3 - Less than, 4 - Less than or equal, 5 - Greater than, 6 - Greater than or equal
    String search:7 - Begins with, 8 - Does not begin with, 9 - Ends with, 10 - Does not end with, 11 - Contains, 12 - Does not contain
    Word search:13 - Any word begins with, 14 - No word begins with, 15 - Any word ends with, 16 - No word ends with, 17 - Any word equals to, 18 - No word equals to

  • Wildcards


    In string filter is possible to use wildcards if SearchOptions contains Wildcards keyword, "?" to replace one character (defined by Cfg SearchReplaceOne ), "*" to replace none, one or more characters (defined by Cfg SearchReplaceMore).

  • Search settings


    Some of the global search setting can be changed by users in popup menu for Tool cell D: Search.
    When comparing values for search it is possible to ignore case (Cfg SearchCaseSensitive), diacritics (Cfg SearchLocaleCompare), some characters (usually spaces) (Cfg SearchWhiteChars ), etc.
    To change the way the cell values are compared, set cell attribute SearchValue to use this value instead of the cell value for comparing.
    How the cell value will be formatted for search can be set by Cfg SearchType.
    The search can by run asynchronously with progress dialog and cancel button shown when search time is higher than MaxSearchTime .

  • Search restrictions


    To not search in the row or column, set its attribute NoSearch.
    To not search in the cell, set its NoSearch, this attribute is read only if set FV&32.
    It is possible to specify which rows and column will be searched in SearchRows / SearchCols.
    It is also possible to specify which type of rows and columns will be searched by SearchRowsType / SearchColsType.
