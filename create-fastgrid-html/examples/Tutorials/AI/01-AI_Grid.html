1. Grid with AI

Basic grid with integrated AI
Source: 01-AI_grid.js

  • Set up AI

    • Now implemented communication and API for OpenAI ChatGPT.
    • There are two ways to use OpenAI with FastGrid: purchase AI credit from COQsoft or purchase API key from OpenAI

    • Purchase AI credit from COQsoft

      • Purchase AI credit in our e-shop at https://www.treegrid.com/Purchase?ai=100
      • Pass the purchased AI credit to FastGrid in AI tag Credit or enter it directly to FastGrid in AI settings menu.

    • Create OpenAI API key

      • Create your own API account on OpenAI (https://platform.openai.com/docs/quickstart).
      • Create your API key and set it to FastGrid AI communication settings.
      • For

        development

        you can set it directly to OpenAI Responses API as AI: { Url: "https://api.openai.com/v1/responses", Header: { Authorization: "Bearer ..." } }.
      • For

        production

        you should create your server side url to use as a bridge between FastGrid and OpenAI, use the API key in your server code, and pass its url to AI: { Url:"..." }. To not reveal your secret API key to your visitors.

  • Set up grid for AI

    • Add AI toolbar to the grid, usually to grid Bottom by Bottom:["AI"].
      To split the AI toolbar to two rows, use Bottom:["AIInput","AIOutput"].
      In Sheet the AI toolbar is shown (on top) by default, if you want to not use AI, hide it by Bottom:[{id:"AI",Hidden:1}].
    • Next you should precisely describe your grid to AI, its structure, data, sense and behavior, in AI: { StaticInstructions:"..." } or dynamically in API event OnAIGetStaticInstructions.
      For start and base testing you can use built-in instructions and set only grid Description.
    • Next you should precisely describe your grid actual state and settings to AI in AI: { DynamicInstructions:"..." } or dynamically in API event OnAIGetDynamicInstructions.
      For start and base testing you can use built-in instructions.
    • If AI is permitted to search Internet by WebSearch, set or clear the AI UrlDownload as URL for downloading files without CORS.

  • More AI settings

    • By default is used gpt-nano model. To use different model or its version, set it by Cfg AIModel and optionally add and define it in AI Models.
    • By default the prompt input is sent to AI by clicking to Accept button next to the prompt or by pressing Enter during the prompt editing.
      To send the prompt input on any end editing (e.g. click outside) or not by pressing single enter, set appropriate value to Cfg attribute AIAccept.
    • By default the AI can search Internet and download text files from web sources to fulfill the requests. To restrict it, set Cfg attribute AIWebSearch = 0.
      To limit the downloaded file size and downloading time set AI attributes MaxDownloadSize and MaxDownloadTime.
    • The AI can have full control on the grid or can change only its view or can only read the grid data. It can be chosen by Cfg attribute AIPermissions and the individual permission levels can be set up by locks in AILockAI0, AILockAI1, ...
    • During AI communication the grid can be disabled and show progress message or just locked and be still accessible. Control it by Cfg attribute AIDisableGrid.
    • For debug purposes is possible to display the grid tool calls done by AI by setting Cfg attribute AIOutputFunction
    • These settings can be also controlled by users via AI settings menu, the items in this menu can be chosen by Cfg attribute AIMenu
