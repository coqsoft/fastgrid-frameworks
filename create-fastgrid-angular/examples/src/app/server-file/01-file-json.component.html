1. Data in static JSON file

Loading data from static JSON file on Node server and saving changes back to this file
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/File.js?func=get&file=JsonData.js and saved to url http://localhost:8000/File.js?func=set&file=JsonData.js. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in file ./server/JsonData.js and the script loading and saving data is located at ./server/File.js
