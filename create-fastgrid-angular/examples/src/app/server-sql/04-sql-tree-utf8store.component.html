4. Tree table from SQL server using UTF8Store

Loading data in tree from and saving data to SQLite database table on Node server in short format UTF8Store
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/SQLTreeUTF8Store.js?func=get and saved to url http://localhost:8000/SQLTreeUTF8Store.js?func=set. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in ./server/sqlite.db database file in table TreeData and the script loading and saving data is located at ./server/SQLTreeUTF8Store.js
  • This example uses UTF8 Store to code all data sent from server to one short UTF8 string.
    In this sample the resulted data are shorten by about 1.4 times to about 70% of original JSON size. The UTF8 Store is not too effective here, because the most of data are long unique product names. Compare: UTF8 Store vs. JSON.
