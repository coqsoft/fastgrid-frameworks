2. Data in static UTF8Store file

Loads data from static UTF8Store file and loads and saves changes back to the next JSON file on Node server
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/File.js?func=get&file=UTF8StoreData.js and from also http://localhost:8000/File.js?func=get&file=UTF8StoreChanges.js and saved to url http://localhost:8000/File.js?func=set&file=UTF8StoreChanges.js. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in file ./server/UTF8StoreData.js and changes are stored in file ./server/UTF8StoreChanges.js and the script loading and saving data is located at ./server/File.js
