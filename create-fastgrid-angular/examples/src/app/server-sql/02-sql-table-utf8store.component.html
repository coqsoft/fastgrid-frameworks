2. Plain table from SQL server using UTF8Store

Loading data from and saving data to SQLite database table on Node server in short format UTF8Store
  • Sample Node server must be running on http://localhost:8000. The sample Node server package is located at ./server/.
    The sample data are loaded from http://localhost:8000/SQLTableUTF8Store.js?func=get and saved to url http://localhost:8000/SQLTableUTF8Store.js?func=set. PDF is generated on url http://localhost:8000/Pdf.js?func=getpdf.
    The sample data on server are stored in ./server/sqlite.db database file in table TableData and the script loading and saving data is located at ./server/SQLTableUTF8Store.js
  • This example uses UTF8 Store to code all data sent from server to one short UTF8 string.
    In this sample the resulted data are shorten by about seven times to about 15% of original JSON size. Compare: UTF8 Store vs. JSON.
