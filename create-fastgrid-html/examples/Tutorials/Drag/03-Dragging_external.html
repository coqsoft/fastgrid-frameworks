3. Dragging from and to external sources

Dragging rows, columns and cell values from and to outside
Source: 03-Dragging_external.js
Drag grid rows, columns or cells here. To drag grid cell on touch screen, focus it first.

  • Dragging cell to external source


    To permit dragging individual cells assign action DragCell to OnDragAny event in Actions or in individual cell / row / column attribute. If used in Actions, to preserve dragging whole rows / columns by Header, preserve here also the Drag action, e.g. OnDragAny:"Focus(), Drag(0,15,1) || DragCell()".
    And define API event OnDropCell to do the required action after the cell is dropped inside or outside the grid.
    Optionally define also API event OnDragCell to control something during dragging, e.g. visually highlight tags with dropping permissions.

  • Dragging row(s) / column(s) to external source


    Rows and columns can be dragged outside grid by default set by DraggingRows / DraggingCols.
    Define API event

    OnDrop

    or

    OnDropped

    to do the required action after the row or column is dropped outside (or inside) the grid.
    If permitted dragging more selected rows or columns, get the dragged selection by API method GetSelection.
    Optionally define also API event OnDragging to control something during dragging, e.g. visually highlight tags with dropping permissions.

  • Dragging cell from external source to grid


    To start dragging cell from outside call API method DragCell. It behaves like the action DragCell for dragging from grid.
    Define API event OnDropCell to do the required action after the cell is dropped inside or outside the grid.
    Optionally define also API event OnDragCell to control something during dragging, e.g. visually highlight tags with dropping permissions.

  • Dragging row / column from external source to grid


    To start dragging row(s) from outside call API method DragRow. To start dragging column(s) from outside call API method DragCol.
    These methods add hidden row(s) or column(s) to grid and start their dragging.
    Define API event

    OnDrop

    or

    OnDropped

    to do the required action after the row or column is dropped inside (or outside) the grid. If drop is accepted, show the dropped row(s) or column(s) by Hide API method. If drop is rejected, remove the temporary row(s) or column(s) from grid by Delete API method.
    Optionally define also API event OnDragging to control something during dragging, e.g. visually highlight tags with dropping permissions.
